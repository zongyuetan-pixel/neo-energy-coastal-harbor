# NEO ENERGY · 海岸充电港

基于 Three.js 的新能源充电站，使用完整的本地 GLB 新能源轿车模型；充电桩、风机、小船、栈桥及场景装饰由代码生成。

## 启动

使用 Node.js 22.12 或更高的 22.x 版本，先运行 `npm ci`，再运行 `npm start`，访问 `http://127.0.0.1:5173`。

生产版本使用 Vite 构建，Three.js 固定为原有的 0.160.0，与场景代码一同打包。汽车 GLB、内嵌纹理和 Draco 解码器均随项目部署在 `public/`，运行时不依赖模型网站或外部 CDN。其余资源由本地代码和 Canvas 生成，字体沿用系统字体设置。

浏览器的 `file://` 安全限制可能阻止模块导入，请使用上面的本地服务器。

## 交互

- **点击小车**：选中无 Logo 的 Model 3 风格白色轿车，再点击道路目的地，沿较短道路路线行驶并停车。点击车后方会自动挂倒挡，限制倒车速度、点亮倒车灯，车头保持朝前；前轮随弯道转向。绿色标记与虚线显示目标和路线。可继续点击道路重新选择目标。点击海面或绿化区不会触发行驶，拖动鼠标只旋转镜头。
- **点击充电车位**：车辆自动前往车位并插枪充电；充电时点选新的道路目的地，会先归还充电枪，再驶出车位前往目标。
- **C / 环路巡航按钮**：向前沿连接充电站的环路行驶，再次按下暂停或继续。绕行后自动返回所选车位充电。
- **巡航期间按 WASD / 方向键**：切回手动驾驶；Esc 暂停巡航。
- **WASD / 方向键**：前后驾驶、转向。空格刹车。
- **P / 自动泊车充电**：驶入选中的 EV 01–04 车位，停稳后自动插枪。
- **驶出车位**：充电枪归位，车辆返回前方道路。
- **R / 重置场景**：恢复车辆、奖励与全景镜头。
- **全景 / 车辆特写 / 充电桩 / 海港**：切换镜头；支持鼠标旋转、缩放。
- **交易所**：查看充电桩后方“中港世纪web3-专属RWAT交易所（CEX）”透明 App 卡片；报价、最新 K 线、均线和成交量自动变化，每 3.2 秒生成一根新蜡烛，全部使用本地模拟行情。
- 手机屏幕提供方向按钮。

充电时奖励从 +100 增加到 +1000 RWAT。充电枪插稳后持续向预言机、联盟链和交易所发送数据，奖励到顶和充满不会中断；拔枪、接触断开后停止发送。充满后的数据保留最终电量，不继续虚增电量。上链卡片是场景动画演示，没有连接钱包或区块链服务。

## 文件

- `src/ev-car.js`：加载完整 GLB 轿车，保留外壳、内饰、车窗、灯组和轮组，移除外部品牌标识。独立车轮滚动及前轮转向，右后侧充电口和活动盖板随自动插拔枪动作联动。
- `public/models/electric-sedan.glb`：aarajesh 的《Tesla White car.》开放授权模型，来源和修改说明见 `public/models/CREDITS.txt`；`public/draco/` 包含本地解码器及许可证。
- `src/assets.js`：带屏幕和枪线的充电桩、帆船、游艇及风机模型。风机采用变截面扭转叶片、分节锥形塔筒、螺栓底座、机舱散热格栅、检修扶栏、风速计和淡青状态灯。
- `src/world.js`：车位边线、编号、挡车器、道路、能源驿站、太阳能板、海面、栈桥与系泊绳。
- `src/ring-road.js` / `src/route.js`：与站前公路连接的闭合环路；模型、自动驾驶和手动驾驶边界共用路径。
- `src/landscape.js`：树皮、分枝树干、实例化曲面树叶、草丛和花朵。
- `src/exchange-card.js`：透明交易所卡片及动态模拟 K 线，不连接交易所或钱包。
- `src/energy-network.js` / `src/energy-flow.js`：桩顶脉冲光球直接连接下移到充电桩上方的三路预言机，再传输到联盟链与交易所。传输跟随插枪连接状态，直到实际拔枪才停止；交易所收到完整批次后更新 K 线。所有共识、区块与行情均为本地演示。
- `src/click-navigation.js`：点击目标的路面判定、环路路径与到达停车计算。
- `src/main.js`：灯光、环境反射、柔和泛光、驾驶、自动泊车、插枪和镜头切换。
- `src/style.css`：界面与窄屏布局。

运行 `npm run check` 可以检查所有场景脚本的语法。

运行 `npm test` 检查环路闭合、接缝切线、道路边界和返回各车位的路线。

## Vercel 生产部署

- 正式公开地址：`https://neo-energy-coastal-harbor.vercel.app`。
- Vercel 项目：`tim-z-y-projects/neo-energy-coastal-harbor`；当前通过官方 CLI 发布到 Production，GitHub 自动部署尚未连接。
- GitHub 仓库生产分支：`main`。
- 框架：Vite；安装：`npm ci`；构建：`npm run build`；输出目录：`dist`。
- `vercel.json` 已配置构建和带内容哈希的资源缓存，无需环境变量或服务端。
- `npm run check`、`npm test`、`npm run build` 用于发布前验证；`npm run preview` 在本机 4173 端口预览真实产物。
- 这是单页三维场景，五个视角均在首页内切换，没有其他客户端路由，不需要将丢失的资源重写到首页。
- 原 `.openai/hosting.json` 仅保留旧站点记录，不参与 Vercel 构建。生产产物不包含本地服务器、临时文件或平台凭据。
- `.vercelignore` 排除项目参考资料、旧平台元数据、测试截图、缓存和本地环境文件；模型与解码器通过 `public/` 完整部署。
- 在 Vercel 导入 GitHub 仓库后，将 Production Branch 设置为 `main`；公开分享需关闭 Production 的 Deployment Protection。后续推送到 `main` 自动生产部署。
