# NEO ENERGY · 海岸充电港

基于 Three.js 的程序化新能源充电站。所有小车、充电桩、风机、小船、栈桥及场景装饰都由代码生成，不需要下载额外模型。

## 启动

在本目录运行 `npm start`，访问 `http://127.0.0.1:5173`。无需安装 npm 依赖；首次访问需要联网加载固定版本的 Three.js 0.160.0。

浏览器的 `file://` 安全限制可能阻止模块导入，请使用上面的本地服务器。

## 交互

- **点击小车**：选中无 Logo 的 Model 3 风格白色轿车，再点击道路目的地，沿道路行驶并在目标位置停车；绿色标记与虚线显示目标和路线。可继续点击道路重新选择目标。点击海面或绿化区不会触发行驶，拖动鼠标只旋转镜头。
- **点击充电车位**：车辆自动前往车位并插枪充电；充电时点选新的道路目的地，会先归还充电枪，再驶出车位前往目标。
- **C / 环路巡航按钮**：向前沿连接充电站的环路行驶，再次按下暂停或继续。绕行后自动返回所选车位充电。
- **巡航期间按 WASD / 方向键**：切回手动驾驶；Esc 暂停巡航。
- **WASD / 方向键**：前后驾驶、转向。空格刹车。
- **P / 自动泊车充电**：驶入选中的 EV 01–04 车位，停稳后自动插枪。
- **驶出车位**：充电枪归位，车辆返回前方道路。
- **R / 重置场景**：恢复车辆、奖励与全景镜头。
- **全景 / 车辆特写 / 充电桩 / 海港**：切换镜头；支持鼠标旋转、缩放。
- **交易所**：查看充电桩后方“中港世纪web3-专属RWAT交易所（CEX）”透明 App 卡片；报价、最新 K 线、均线和成交量自动变化，每 3.2 秒生成一根新蜡烛，全部使用本地模拟行情。
- 手机屏幕提供方向按钮。

充电完成时奖励从 +100 增加到 +1000 RWAT。上链卡片是场景动画演示，没有连接钱包或区块链服务。

## 文件

- `src/assets.js`：无 Logo、Model 3 风格的程序化白色轿车、带屏幕和枪线的充电桩、帆船、游艇及风机模型。
- `src/world.js`：车位边线、编号、挡车器、道路、能源驿站、太阳能板、海面、栈桥与系泊绳。
- `src/ring-road.js` / `src/route.js`：与站前公路连接的闭合环路；模型、自动驾驶和手动驾驶边界共用路径。
- `src/landscape.js`：树皮、分枝树干、实例化曲面树叶、草丛和花朵。
- `src/exchange-card.js`：透明交易所卡片及动态模拟 K 线，不连接交易所或钱包。
- `src/data-pipe.js`：两张卡片之间的透明连接管道、接口光环与流动数据包；充电时加速，镜头或车位改变时更新连接点。
- `src/click-navigation.js`：点击目标的路面判定、环路路径与到达停车计算。
- `src/main.js`：灯光、环境反射、柔和泛光、驾驶、自动泊车、插枪和镜头切换。
- `src/style.css`：界面与窄屏布局。

运行 `npm run check` 可以检查所有场景脚本的语法。

运行 `npm test` 检查环路闭合、接缝切线、道路边界和返回各车位的路线。
